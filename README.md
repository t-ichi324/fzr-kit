# Fzr/Kit-Lite

A lightweight collection of modern PHP utility classes (Date, IO, Util, SEO) with no external dependencies.

## Features

- **Date & Wareki**: Japanese calendar support
- **IO Utilities**: File and directory utilities
- **String/Array/Number Utilities**: Fluent APIs for data manipulation
- **SEO**: Meta and Sitemap utilities

## Installation

```bash
composer require fzr/kit-lite
```
